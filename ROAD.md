 # web layanan publik = Sakalputung
 # fitur fitur admin
    - dashboard admin
    - authentikasi login admin menggunakan nama rt 1-5
    - melihat data penduduk yang ada di desa sakalputung dari rt 1-5 terdiri dari nama, umur, rt
    - mengelola laporan dari warga, sudah di kerjakan, belum di kerjaka, menunnggu info lanjut
    - menambahkan berita yang beredar di desa dan akan di tampilkan di tampilan pengguna
    - setiap penduduk menampilkan alamat rumah melalui maps jadi setiap data penduduk harus ada alamat rumah
    - setiap ada surat dari pusat admin dapat memberikan kabar surat tersebut dengan di bagikan otomatis 
    - admin membuat forum donasi untuk kegiatan desa menggunkan payment gateway
# fitur fitur pengguna
    - warga login menggunakan gogle atau nomer, authentikasi agar aman
    - mengisi data warga seperti nama, umur, rt, alamat setelah sudah arahkan ke tampilan website
    - warga dapat melaporkan kendala yang terjadi di desa dengan foto dan memberikan keluhan
    - warga dapat melihat berita yanng beredar di desa
    - warga mendapatkan pesan dari admin adanya surat yang di kasih dari pusat
    - warga dapat mendonasikan uang untuk kegiatan di desa
# bahasa pemrograman
    - golang
    - supabase
    - react
    - tailwind css
    - payment getway
